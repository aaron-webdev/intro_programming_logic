# Debugging

### Goal of testing and debugging
- find all of errors befor deploying the program

### types of errors
- syntax errors
    - compile time error
    - caught before the program runs
- runtime errors
    - throws an exception that will stop the program
- logic errors
    - hardest to find
    - everything works just not correctly
    
### steps of testing
- use known valid data to test intended outcome
- use known bad data to test for weakness
